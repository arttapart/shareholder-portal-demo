# پیش‌نمایش پرتال سهامداران

نسخه‌ی ایستای پیش‌نمایش با ۱۰ سهامدار ساختگی. همه‌ی اطلاعات ساختگی است و برگه‌های سهام «نمونه آزمایشی · فاقد اعتبار» هستند.

- ورود سهامدار: نام کاربری = شماره سهام (مثلاً 1001)، رمز = کد ملی (فهرست زیر فرم ورود). در این نسخه تغییر اجباری رمز حذف شده است.
- ورود مدیر: `admin` / `Admin12345`

ذخیره‌سازی، بارگذاری اکسل و چاپ در این نسخه غیرفعال است.
